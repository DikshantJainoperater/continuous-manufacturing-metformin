# Continuous Manufacturing of Sustained-Release Metformin Tablets Using Aspen Plus V14

## Project Overview

This repository contains my MSc dissertation completed at the **University of Surrey** as part of my Master's degree in 2026.

The project focuses on the **continuous manufacturing of sustained-release Metformin tablets** using **Aspen Plus V14**. The complete pharmaceutical manufacturing process was designed and simulated from scratch, demonstrating how continuous manufacturing can improve production efficiency, product quality, and process stability.

---

## Why I Chose This Project

Diabetes is one of the fastest-growing health challenges worldwide, and Metformin is one of the most widely prescribed medicines for its treatment. As the demand for this medicine continues to increase, there is a need for faster, more efficient, and reliable manufacturing methods.

I chose this project because I wanted to learn how continuous manufacturing can improve pharmaceutical production and support the future of medicine manufacturing through process simulation and optimisation.

---

## Project Objectives

- Design a complete continuous manufacturing process for Metformin tablets.
- Build the entire process in Aspen Plus V14 from scratch.
- Simulate pharmaceutical unit operations.
- Optimise important operating parameters.
- Perform sensitivity analysis to understand process behaviour.
- Evaluate process performance under different operating conditions.

---

## Software Used

- Aspen Plus V14

---

## Process Flow

The complete manufacturing process was developed using Aspen Plus and included the following unit operations:

- Mixer
- Reactor
- Wet Granulator
- Fluid Bed Dryer
- Mill
- Compressor
- Filters
- Pumps
- Product Streams

The process follows a continuous wet granulation approach for sustained-release tablet manufacturing.

---

## Parameters Optimised

During this project, I analysed the effect of several important process parameters, including:

- Temperature
- Pressure
- Feed Rate
- Air Flow Rate
- Binder Flow Rate
- Residence Time
- Conversion
- Yield
- Granulator Shear
- HPMC Concentration

---

## Sensitivity Analysis

Several operating scenarios were investigated to understand their impact on process performance.

The study included:

- Increasing dryer temperature
- Reducing binder flow
- Reducing air flow
- Increasing granulator shear
- Increasing HPMC concentration

Each scenario helped identify process limitations, operating challenges, and opportunities for optimisation.

---

## Key Results

The developed Aspen Plus model successfully simulated a continuous pharmaceutical manufacturing process for sustained-release Metformin tablets.

The project demonstrated:

- Successful process simulation
- Process optimisation
- Sensitivity analysis
- Stable process modelling
- Identification of critical process parameters
- Troubleshooting of simulation errors
- Comparison with published literature for validation

---

## Challenges Faced

During the project, I encountered several simulation challenges including:

- Pressure imbalance in the fluid bed dryer
- Particle size distribution (PSD) warnings
- Missing component property data
- Model convergence issues

These problems were resolved through parameter optimisation, process adjustments, and iterative troubleshooting within Aspen Plus.
